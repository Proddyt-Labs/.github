## Proddyt Labs

Homelab e laboratório de projetos do [Proddy-0](https://github.com/Proddy-0) · [proddyt.com](https://proddyt.com) · [marca](https://proddyt-labs.github.io/brand/)

### Proddyt Studio

<img src="https://cdn.jsdelivr.net/gh/Proddyt-Labs/brand@1/marks/studio-mark.svg" width="32" height="32" alt="">

Suíte de 12 apps desktop de criação e escritório: forks dos [Crafting Apps (ArtCraft)](https://github.com/storytold) — reimplementações open-source em Rust — com features próprias, sincronia com o original e build automático (Windows, Linux e macOS, portátil + instalador com atualização dentro do app).

**Site e downloads:** https://switch.proddyt.com
